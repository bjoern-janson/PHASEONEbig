# adaptive-loop-conformance-001

## Question

Can the **unchanged** `adaptive-loop-protocol-001` survival protocol host two genuinely different ontologies without adding a universal primitive?

Domains:

1. Trace the Ace predictive representation change.
2. Symbolic program repair with executable programs and held-out behavioral tests.

This is a **conformance experiment**, not `protocol-002`.

## Frozen protocol identity

The original generated protocol source is preserved separately under `artifacts/adaptive-loop-protocol-001/`. The conformance experiment used those source files byte-for-byte; source hashes are recorded in `FROZEN_PROTOCOL_SHA256.txt`.

No protocol source file was edited.

## Shared transition grammar

```math
(R_i,K_i) \xrightarrow{D_i,T_i} R_i' \xrightarrow{F_i} C_{improve}
\xrightarrow{inherit/reject} (R_{i+1},K_{i+1}).
```

The core does **not** define the ontology of `D`, construct `T`, prove independence of `F`, define `V`, prove minimality, or discover the next `D`.

## Trace success branch

A one-change conformance recomputation uses an objective-prior incumbent and adds only the 13 predeclared direct transcript-structure observables. Evaluation is on session-held-out seed 23, which was not the construction surface used to select the structure distinction.

- incumbent LL: `0.5518725935510772`
- candidate LL: `0.5425176010683584`
- `C_improve = +0.00935499248271876`
- decision: **INHERIT**

This is conformance evidence only. It does not mutate Groundup-001 and does not create Groundup-002.

## Trace rejection branch

The already-frozen lexical objective-dialogue scalar is evaluated on cold-objective seed 52.

- incumbent LL: `0.6160420260629641`
- candidate LL: `0.6160997555644535`
- `C_improve = -0.000057729501489411916`
- decision: **REJECT**
- incumbent remains Groundup-001
- K appends the failed experiment event

## Symbolic program repair success branch

Specification: return `1` iff integer `x` is even.

Incumbent:

```python
def classify(x):
    return 0
```

Candidate:

```python
def classify(x):
    return int(x % 2 == 0)
```

Held-out future: `(-6, -5, 8, 9)`.

- incumbent accuracy: `0.5`
- candidate accuracy: `1.0`
- `C_improve = +0.5`
- decision: **INHERIT**

## Symbolic program repair rejection branch

Candidate repair instead adds a sign predicate:

```python
def classify(x):
    return int(x < 0)
```

On the same held-out behavioral future:

- incumbent accuracy: `0.5`
- candidate accuracy: `0.5`
- `C_improve = 0.0`
- decision: **REJECT**
- incumbent program survives
- K still appends the failed experiment event

## Result

The narrow survival-transition abstraction survives this ontology change **without a protocol edit**.

```math
\boxed{\text{same frozen protocol} + \text{different ontology} \rightarrow \text{both survival branches represented}}
```

### Claim ceiling

This establishes only:

> `adaptive-loop-protocol-001` can enforce its declared identity, parentage, decision-rule, survival, and evaluated-experiment knowledge-update bookkeeping for these two domains without encoding either domain's ontology.

It does **not** establish that the protocol is sufficient for intelligence, adaptation, corrigibility, causal identification, statistical independence, or minimal transformation.

## Important pressure point — OPEN, not patched

`State.knowledge` in PROTOCOL-001 is an append-only tuple of `KnowledgeEvent`s generated by `reconstitute()`. Therefore it naturally records knowledge from **evaluated candidate transitions**.

The live Trace research state `K3`, however, also contains diagnostic-only updates such as residual-collision and relational-collision audits that changed the research question **without producing a Candidate + Consequence transition**.

So there are two possible interpretations:

1. **Narrow K:** core `K` means only the survival-transition ledger. Then PROTOCOL-001 remains internally coherent, while the broader research/search state lives outside the core.
2. **Full K:** core `K` is intended to be the entire research state. Then PROTOCOL-001 cannot currently represent `K2 -> K3` faithfully without an evaluated candidate transition.

This experiment does **not** choose between them and does **not** add a new primitive. The pressure point is recorded as evidence for the next abstraction decision.

That is exactly the purpose of conformance-before-enhancement.
