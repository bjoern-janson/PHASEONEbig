# Case Studies

These case studies are **methodological stress tests**, not substitutes for controlled empirical evidence.

Their purpose is to examine whether the program's distinctions remain useful when confronted with complicated real-world systems containing incomplete information, competing causal explanations, path dependence, distributed observation, institutional interfaces, and high-stakes consequences.

The governing rule is:

```math
\boxed{\text{case-study relevance}\neq\text{causal evidence for }C_{\rm improve}}
```

A case study may:

- expose a collapsed distinction;
- reveal competing causal graphs that fit overlapping observations;
- clarify which boundaries must be preserved;
- show where hindsight, authority leakage, or representation failure can corrupt inference;
- generate questions for later experiments.

A case study may **not** by itself:

- establish a causal contribution;
- establish legal, medical, or moral responsibility;
- validate a mechanism merely because the narrative is compelling;
- promote an interpretation into the core theory.

For contested cases, separate at minimum:

```text
established / undisputed fact
litigated allegation or argument
expert interpretation
secondary commentary
research inference
unearned hypothesis
```

and preserve the boundary:

```math
\boxed{\text{detection of anomaly}\neq\text{identification of cause}}
```
